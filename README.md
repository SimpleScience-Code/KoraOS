# KoraOS
This is my first WebOS, KoraOS, named after my favourite block in Minecraft, "coral" but without "c" and "l"...lol
I made this not only for the mission in Stardance but for my own pleasure, to satisfy an itch to make my own system, so enough about me, on to the OS
